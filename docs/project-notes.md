The supplied archive contained multiple duplicate scripts, scratch files named `untitled*.py`, cached bytecode, local absolute paths, raw CSV/XLSX datasets, a nested copy of another repository, and academic documents. These were not copied into this public-facing repository to keep the portfolio focused and reduce accidental disclosure of private or third-party material. Keep the original ZIP as a private backup.
